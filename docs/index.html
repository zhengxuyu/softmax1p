softmax1p

Drop-in log_softmax, softmax and cross_entropy for PyTorch, JAX and TensorFlow that do not suffer from Softmax Collapse. An implementation of Barron, Gnanapragasam & Tschannen, A Fix for Softmax and Cross-Entropy (2026).

Install

pip install softmax1p           # no framework pulled in
pip install "softmax1p[torch]"  # or [jax], [tf]
import torch
from softmax_torch import log_softmax, softmax, log_prob_of, cross_entropy

logits = torch.randn(8, 32000, requires_grad=True)
target = torch.randint(0, 32000, (8,))

loss   = cross_entropy(logits, target)   # class dim LAST: logits [..., C], target [...]
lp     = log_prob_of(logits, target)     # log p(target) per row
lp_all = log_softmax(logits, dim=-1)     # same signature as torch.log_softmax
import jax
from softmax_jax import log_softmax, softmax, log_prob_of, cross_entropy

logits = jax.random.normal(jax.random.key(0), (8, 32000))
target = jax.random.randint(jax.random.key(1), (8,), 0, 32000)

loss   = jax.jit(cross_entropy)(logits, target)   # jit / vmap / grad all work
lp_all = log_softmax(logits, axis=-1)
import tensorflow as tf
from softmax_tf import log_softmax, softmax, log_prob_of, cross_entropy

logits = tf.random.normal((8, 32000))
target = tf.random.uniform((8,), 0, 32000, dtype=tf.int64)

loss   = cross_entropy(logits, target)   # eager or inside tf.function
lp_all = log_softmax(logits, axis=-1)

The problem

The standard log-softmax subtracts the largest logit and computes log(1 + Σj≠max e−(zmax−zj)). When the top logit leads by a margin m where e−m is below half an ulp of 1, 1 + e−m rounds to exactly 1. The target's log-probability and gradient become exactly 0 while the other classes keep nonzero gradients, so the row's gradient no longer sums to zero. With Adam, that bias turns into slingshot loss spikes and parameter drift.

standard: log(1 + 3e−m)
softmax1p: −softplus(LSE)
dtypecollapse margin
bfloat16≈ 5.5
float16≈ 7.6
float32≈ 16.6

The fix

Never form 1 + e−m. Set the argmax (or target) slot to an exact 0, take the log-sum-exp over the other slots only, and join the two with softplus:

sk = 1[k ≠ argmax] · (zk − zmax)
log_softmaxk = sk − softplus( LSEj≠argmax sj )
log p(t) = −softplus( LSEj≠t (zj − zt) )

The kept logit enters the result only through differences, so autodiff gives it exactly minus the sum of the other gradients and the row gradient sums to zero by construction.

API

The three softmax_* modules expose the same four functions. PyTorch takes dim, JAX and TensorFlow take axis.

log_softmax(z, dim=-1)

Log-softmax along dim. Same shapes as the framework's built-in.

softmax(z, dim=-1)

exp(log_softmax(z, dim)).

log_prob_of(z, target)

log_softmax(z)[..., target] over the last dimension, for integer target of shape z.shape[:-1]. Cheaper than the full log-softmax and useful for policy gradients.

cross_entropy(logits, target, ignore_index=-100, reduction="mean")

Hard-target cross-entropy −log_prob_of(logits, target). The class dimension is last: logits [..., C], target [...]. This differs from F.cross_entropy. Rows whose target equals ignore_index contribute 0 and are left out of the mean. reduction is "none", "sum" or "mean".

Tensor-parallel heads

vocab_parallel_torch.vocab_parallel_log_prob_of(logits_shard, target, group=None, chunk=1024)

Use this for logits split over the class dimension across a torch.distributed group, with equal shards in rank order. target holds global class indices. It is chunked over rows and recomputes the softmax in backward to bound memory. With group=None the logits are treated as unsharded.

vocab_parallel_jax.vocab_parallel_log_prob_of(logits_shard, target, axis_name)

Call this inside jax.shard_map with the vocabulary split along mesh axis axis_name. It communicates with psum / pmax.

Every built-in collapses the same way. The fixed versions recover the exact value to within the dtype's precision and shrink the row-sum error by 7–8 orders of magnitude in fp32 and 3 in bf16. The full margin sweep and test suite are in the README.
